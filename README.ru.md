# Arsenkin MCP

**Запускайте SEO-проверки пакетами из AI-ассистента.**

Собирайте выдачу, проверяйте частотность, кластеризуйте запросы и исследуйте индексацию через Arsenkin Tools. MCP-сервер даёт ассистенту последовательный процесс: оценить запросы, получить согласование, проследить выполнение и разобрать сохранённые результаты.

[Установка](#установка) · [Подключение к ассистенту](#подключение-к-ассистенту) · [Issues](https://github.com/zai-one/arsenkin-mcp/issues)

Например, попросите ассистента:

> Подготовь пакет проверки частотности для моего списка запросов. Покажи план запросов и оценку расходов до отправки заданий.

## Что можно сделать

| Задача | Возможности MCP |
|---|---|
| Исследовать семантику | Частотность, сбор фраз, динамика спроса, поисковые подсказки и кластеризация. |
| Проверить поисковую видимость | Проверки выдачи, позиций, индексации и релевантных URL. |
| Управлять пакетом заданий | Оценка, согласование, запуск, отслеживание и экспорт сохранённых результатов в CSV или JSONL. |

[Примеры таблиц и диагностика worker](docs/RESULT_TABLES.md#по-русски): каталог профилей, повторяемость URL и доменов в выдаче, записи кластеров и ссылки на исходные данные.

## Установка

Хотите установить готовый пакет? [Установка релиза и создание конфигурации клиента](INSTALL.md#install-a-release-package) работают без клонирования исходников.

Нужны **Python 3.12–3.14** и [uv](https://docs.astral.sh/uv/getting-started/installation/). Можно клонировать проект через Git или [скачать ZIP](https://github.com/zai-one/arsenkin-mcp/archive/refs/heads/main.zip). Для ZIP откройте распакованный каталог и пропустите первые две команды.

Подготовьте API-токен Arsenkin для настройщика. Начните с локальной оценки запроса по примеру ниже; платное выполнение подключите после настройки доступа и лимитов.

```sh
git clone https://github.com/zai-one/arsenkin-mcp.git
cd arsenkin-mcp
uv sync --frozen --extra standalone
uv run --frozen --extra standalone python scripts/configure.py
uv run --frozen --extra standalone arsenkin-mcp --config mcp.local.json --check-config
```

Настройщик создаёт локальную конфигурацию и сохраняет секреты в приватных файлах. Если конфигурация уже существует, он не перезапишет её. `--check-config` проверяет локальные настройки; проверка доступа к аккаунту выполняется отдельно через `arsenkin_status`.

## Подключение к ассистенту

Добавьте конфигурацию в MCP-клиент, использующий раздел `mcpServers` (например, Claude Desktop или Cursor). Замените `/ABSOLUTE/PATH/` своим абсолютным путём; на Windows в JSON можно использовать `D:/Tools/`.

```json
{
  "mcpServers": {
    "arsenkin": {
      "command": "uv",
      "args": [
        "--directory",
        "/ABSOLUTE/PATH/arsenkin-mcp",
        "run",
        "--frozen",
        "--extra",
        "standalone",
        "arsenkin-mcp",
        "--config",
        "/ABSOLUTE/PATH/arsenkin-mcp/mcp.local.json"
      ]
    }
  }
}
```

Клиент сам запускает MCP-сервер. После обновления списка инструментов отправьте первый запрос. Для другого формата конфигурации используйте те же `command` и `args`; `uv` должен быть доступен процессу клиента.

### Первый запрос

> Подготовь оценку проверки частотности одной фразы. Уточни у меня регион и тип частотности; платное задание не отправляй.

Оценка проверяет запрос локально и показывает расчёт сервера без обращения к Arsenkin. Отправка платного задания — отдельный шаг. Расчёт ведётся в настроенных условных единицах: это не гарантированная сумма списания и не цена в рублях.

Если инструменты не появились, проверьте абсолютный путь, доступность `uv` и результат `--check-config`. Для ошибки доступа проверьте учётные данные и права аккаунта. [Подробная установка и диагностика](INSTALL.md).

## Управление доступом и ограничения

Для выполнения настройте лимиты платных задач и согласование, затем запустите worker с той же конфигурацией и SQLite. В экспорте значения сохраняют пути JSON; специализированные SEO-таблицы автоматически не строятся. Отмена задания не гарантирует возврат за уже отправленную работу.

Для работы по сети предусмотрен HTTP с проверкой токенов. [Настройка HTTP](INSTALL.md#http), [конфигурация и права](docs/RUNTIME.md), [подключение Python-пакета](INSTALL.md#python-package-and-platform-integration).

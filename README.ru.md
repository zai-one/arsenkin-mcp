# Arsenkin MCP

MCP-сервер для SEO-задач в Arsenkin Tools. Позволяет готовить и согласовывать платные запросы, запускать отдельные задания или пакеты и получать сохранённые результаты из AI-ассистента.

## Что умеет

- Оценка и подготовка поддерживаемых запросов перед запуском.
- Отправка заданий, проверка статуса, получение результатов и запрос отмены.
- Экспорт сохранённых результатов в CSV или JSONL без запуска нового платного задания.

## Установка

Нужны Git, [uv](https://docs.astral.sh/uv/getting-started/installation/) и Python 3.12–3.14.

Нужен API-токен Arsenkin. Для платных заданий также задайте лимиты расходов, настройте подтверждение и запустите отдельный worker с той же конфигурацией и базой состояния. См. [настройку worker](INSTALL.md#from-a-clone-or-source-zip).

```sh
git clone https://github.com/zai-one/arsenkin-mcp.git
cd arsenkin-mcp
uv sync --frozen --extra standalone
uv run --frozen --extra standalone python scripts/configure.py
uv run --frozen --extra standalone arsenkin-mcp --config mcp.local.json --check-config
uv run --frozen --extra standalone arsenkin-mcp --config mcp.local.json
```

Настройщик сохраняет данные только локально. `--check-config` проверяет локальную
конфигурацию без запросов к провайдеру. Последняя команда ждёт подключения MCP-клиента.

Инструкции подключения и установки пакета: [INSTALL.md](INSTALL.md).

## Возможности и ограничения

В CSV и JSONL значения сохранённого ответа представлены вместе с их путями в JSON. Специализированных SEO-таблиц с отдельным набором колонок для каждого типа задания пока нет. Подробнее: [выполнение заданий и лимиты расходов](docs/RUNTIME.md).
